### `№ 03` — COMO TRABALHO

> *Quatro princípios.*

| | |
|---|---|
| `01 / Pragmático` | **Resolvo o problema do cliente,** *não exibo código bonito. Entrega > perfeição.* |
| `02 / Multi-tenant` | **Penso isolamento, billing e onboarding** *desde a primeira linha do schema.* |
| `03 / Deploy contínuo` | **CI/CD, observabilidade, rollback.** *Produção é sagrada.* |
| `04 / Vertical` | **Conheço o negócio do cliente.** *Código é consequência do entendimento.* |
